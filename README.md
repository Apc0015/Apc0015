### Engineering Focus

I design and build production AI systems where **deterministic security, verifiable execution, and rigorous evaluation** come first:

- **Governed Enterprise RAG:** Enforcing pre-LLM data firewalls with role-, row-, and column-level access control (RBAC) and prompt-injection defense so unauthorized data never enters model context.
- **Multi-Agent Workforce Governance:** Designing execution foundations where autonomous agents are gated by deterministic policy engines, audit trails, and verification checks.
- **RAG Red-Teaming & Evaluation:** Building synthetic adversarial dataset generators and automated evaluation harnesses to catch retrieval failures and hallucinations before deployment.
- **Graph & Edge Intelligence:** Developing Graph Neural Networks (GAT, GCN, GraphSAGE) on large-scale citation networks and optimizing lightweight RAG pipelines for constrained edge hardware.
